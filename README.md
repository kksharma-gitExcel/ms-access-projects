### 📝 PROJECT OVERVIEW
This repository contains two Access database projects developed for managing a book collection and course registration. It also showcase the usage of Excel (especially Power Query).

---

#### 📚 Book Collection Database
Database designed to manage and organize a collection of books.

##### 🗃️ Files:
* `BookCollection.accdb` - Main Access file
* `BookData.xlsm` - Main data source file for Access
* `BookInfo_1.txt`/`BookInfo_2.txt`- Data source for `BookData.xlsm`

##### 📁 What database file contains:
* **Tables :** Stores data for Books, Publishers, Genres and Authors
* **Queries :** Answering some of the questions like `Books with single author`, `Books with more than one author`, `Top 10 Genres` etc.
* **Forms :** Form that lets you add your book to the collection of books with their author, genre and publisher.
* **Reports :** Just show the summary and key metric, like `Total Books`, `Total Authors`, `Total Genre` etc.

---

####  📚 Course Registration Form Database
Database designed to record the student and their course registration information.

#####  🗃️ Files:
* `Course Registration system.accdb` - Main Access File
* `Course Registration system (Information or details)` -  Excel file containing the info about table, fields and their data type.

##### 📁 What database file contains:
* **Tables :** Stores data for Students, Courses, and their Registrations
* **Queries :** Includes queries to check students for a specific course and courses for a specific student. (These are supporting queries primarily used for creating forms, although they can also be used like any other queries.)
* **Forms :**  Includes forms for student course registration, adding courses, and navigating the database.
* **Report :** Includes a single report that provides a student enrollment summary.
